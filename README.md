# IRP LMS Website

A responsive Learning Management System (LMS) website built using **HTML5 and CSS3**. This project provides a clean and simple platform layout for students to explore courses, follow a structured learning journey, and contact the support team.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Clean and consistent navigation bar
- Home page with a learning journey section
- Courses page with 9 embedded video tutorials
- Contact Us page with contact information and a message form
- Modern UI using CSS Flexbox and Grid
- Responsive layouts using media queries

## 📄 Pages

### 🏠 Home Page

The Home page includes:

- Navigation bar
- Hero section
- Explore Courses button
- Five-step Learning Journey:
  - Learn
  - Practice
  - Build Projects
  - Prepare
  - Get Placed

### 📚 Courses Page

The Courses page includes video tutorials for:

- HTML
- CSS
- JavaScript
- React
- Python
- Java
- Spring Boot
- Hibernate
- Django

### 📩 Contact Us Page

The Contact page includes:

- Email contact information
- Phone number
- Office address
- Contact form with:
  - Full Name
  - Email Address
  - Subject
  - Message
